Given 3*10^13 bytes of memory. Find the maximum number of vertices that can be stored in
that much memory using each of the following three methods:
a) in the form of an adjacency matrix
b) in the form of an edge matrix
c) using lists of neighboring vertices.
The average degree of the vertices is 10^2. Reminder:
1 bit is required to store each cell of a binary matrix.
The vertex lists must store the vertex number, which is an integer,
which we will use 4 bytes to store. One byte is 8 bits.
