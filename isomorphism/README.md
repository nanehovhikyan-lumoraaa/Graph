this is a c program designed to find out whether 2 graphs are isomorphic or not.
The problem is solve using backtracking: every possible option is checked.
If the program can't find a solution it returns a massage saying that the graphs are not isomorphic.
If at least one mapping is found the program returns it.
It also find the adjacency matrixes for 2 graphs and the volume of each of the vertices listed in descending order.

To run the program just type make run in the terminal.
